# MemuMusic

Самостоятельный музыкальный плеер для Windows: локальная медиатека, плейлисты, поиск и загрузки, синхронные тексты, эквалайзер, визуализатор, редактор тегов и статистика прослушиваний. Аккаунт и подписка не нужны.

## Запуск

Скачайте `MemuMusic-Setup.exe` со страницы выпусков и запустите установку. Приложение появится в меню «Пуск» и в списке установленных программ Windows. Python не требуется. Также доступна переносимая версия `MemuMusic.exe`. Окно использует Microsoft Edge WebView2 Runtime, который обычно уже установлен в Windows 10/11.

Импорт файлов и папок находится в настройках медиатеки; аудиофайлы можно также перетащить в окно. Импорт папки хранит ссылки на файлы на месте; загруженные и перетащенные файлы сохраняются в выбранную папку загрузок. `F11` переключает полноэкранный режим. Язык, оформление, очередь и настройки сохраняются между запусками.

Данные хранятся в `%LOCALAPPDATA%\MemuMusic`, отдельно от EXE. Переменная `MEMUMUSIC_DATA_DIR` или аргумент `--data-dir` позволяют выбрать другую папку. Копирование EXE не переносит медиатеку автоматически.

Для загрузок используется yt-dlp. Его можно обновить в настройках загрузок. FFmpeg необязателен: без него доступны локальное воспроизведение и загрузка исходного аудиопотока; конвертация, анализ громкости и некоторые операции с тегами требуют FFmpeg в `PATH` или в папке `bin` внутри папки медиатеки. Доступность онлайн-источников зависит от сервиса, региона и авторизации.

В режиме «Сейчас играет» можно выбирать найденные варианты текста, исправлять их вручную, а для японского, китайского и корейского текста включить офлайн-романизацию. Язык определяется по всему тексту и названию, исполнителю и альбому; если остаются только общие иероглифы, автоматическое различение японского и китайского всё ещё может ошибаться. Оригинал не изменяется.

Раздел «Рекомендации» подбирает похожие треки по медиатеке через YouTube Music. Кнопка прослушивания запускает доступный поток без добавления файла в библиотеку; скачивание выполняется отдельно.

В настройках «Обновления» можно управлять проверкой и загрузкой новых версий. Установка начинается по нажатию кнопки; медиатека сохраняется. Если используется переносимый EXE, обновление откроет установщик. При удалении приложения файлы медиатеки не удаляются.

## Разработка

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m memumusic
```

Сборка Windows EXE: `powershell -ExecutionPolicy Bypass -File build.ps1`. Для установщика требуется Inno Setup 6: после сборки EXE запустите `powershell -ExecutionPolicy Bypass -File build-installer.ps1`.

Локальный веб-интерфейс для отладки без открытия окна:

```powershell
.venv\Scripts\python.exe -m memumusic --serve --data-dir .\build\test-data
```

Сервер слушает только `127.0.0.1` и выбирает свободный порт. Локальная API-сессия защищена cookie и проверкой Origin. Музыка воспроизводится в самом окне; после его закрытия воспроизведение прекращается.
