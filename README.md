# MemuMusic

Самостоятельный музыкальный плеер для Windows: локальная медиатека, плейлисты, поиск и загрузки, синхронные тексты, эквалайзер, визуализатор, редактор тегов и статистика прослушиваний. Аккаунт и подписка не нужны.

## Запуск

Откройте `dist/MemuMusic.exe` или `Start MemuMusic.cmd`. Установка и Python для готового EXE не требуются. Окно использует Microsoft Edge WebView2 Runtime, который обычно уже установлен в Windows 10/11. При его отсутствии установите Evergreen Runtime с сайта Microsoft.

Кнопки «Добавить музыку» и «Добавить папку» находятся слева внизу. Можно также перетащить аудиофайлы в окно. Импорт папки хранит ссылки на файлы на месте; загруженные и перетащенные файлы сохраняются в выбранную папку загрузок. `F11` переключает полноэкранный режим. Язык, оформление, очередь и настройки сохраняются между запусками.

Данные хранятся в `%LOCALAPPDATA%\MemuMusic`, отдельно от EXE. Переменная `MEMUMUSIC_DATA_DIR` или аргумент `--data-dir` позволяют выбрать другую папку. Копирование EXE не переносит медиатеку автоматически.

Для загрузок используется yt-dlp. Его можно обновить в настройках загрузок. FFmpeg необязателен: без него доступны локальное воспроизведение и загрузка исходного аудиопотока; конвертация, анализ громкости и некоторые операции с тегами требуют FFmpeg в `PATH` или в папке `bin` внутри папки медиатеки. Доступность онлайн-источников зависит от сервиса, региона и авторизации.

## Разработка

```powershell
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m memumusic
```

Сборка Windows EXE: `powershell -ExecutionPolicy Bypass -File build.ps1`.

Локальный веб-интерфейс для отладки без открытия окна:

```powershell
.venv\Scripts\python.exe -m memumusic --serve --data-dir .\build\test-data
```

Сервер слушает только `127.0.0.1` и выбирает свободный порт. Локальная API-сессия защищена cookie и проверкой Origin. Музыка воспроизводится в самом окне; после его закрытия воспроизведение прекращается.
